# ROOM — комнатные растения для вашего пространства

ROOM — многостраничный сайт с каталогом комнатных растений, фильтрами, карточками, фотогалереей и советами по уходу. Интерфейс сделан на Bootstrap 5.3.8 с адаптацией для телефона и компьютера.

## Страницы

| Страница | Что находится внутри |
| --- | --- |
| `index.html` | Главная, популярные растения, идеи для интерьера |
| `catalog.html` | Девять растений, поиск по названию, фильтры по свету и уходу, сортировка по цене, размеры, быстрый просмотр |
| `product.html?plant=monstera` | Подробная карточка выбранного растения, два фото с переключением, характеристики, похожие растения, вопросы и ответы |
| `care.html` | Короткий гид по освещению, поливу и первым неделям дома |
| `gallery.html` | Фотогалерея идей размещения растений |
| `about.html` | Подход ROOM к выбору растений |
| `order.html` | Форма подбора с проверкой полей и автоматическим выбором растения из каталога |

Всего семь HTML-страниц. Карточка товара получает название растения из параметра `plant` в адресе. Ссылки между страницами относительные, поэтому сайт работает и в подпапке GitHub Pages.

## Как пользоваться

1. На главной откройте каталог или галерею идей.
2. В каталоге найдите растение по названию, освещению или сложности ухода и отсортируйте товары по цене.
3. Откройте быстрый просмотр или подробную карточку, переключите фотографии и посмотрите похожие растения.
4. Перейдите к форме: выбранное растение подставится автоматически.
5. После заполнения форма покажет предварительный результат. Отправка пока не подключена, данные никуда не передаются.

Теперь можно также добавить растения в избранное и корзину, написать отзыв на странице растения и открыть личный кабинет. Все эти данные сохраняются только в текущем браузере. Оформление из корзины создаёт локальную запись в истории кабинета; магазин не получает заявку, а онлайн-оплаты и регистрации пока нет.

Анимации появления поддерживают настройку системы «Уменьшить движение».

## Технологии

- HTML5, CSS3, JavaScript;
- локальный Bootstrap 5.3.8 (`vendor/bootstrap/`);
- компоненты Bootstrap: сетка, навигация, карточки, форма, модальное окно, таблица, accordion, уведомления и хлебные крошки;
- локальные фотографии в `images/photos/` (Unsplash), запасная иллюстрация `images/plant.svg`;
- GitHub Pages.

Стили сайта находятся в `css/custom.css`, сценарии поиска, фильтров, карточки и формы — в `js/app.js`. Для просмотра локально откройте `index.html` в браузере; сборка и сервер не требуются.

Размеры горшков и высота приведены как примеры характеристик для каталога. Контактные данные в футере вымышлены и не принимают обращения.
