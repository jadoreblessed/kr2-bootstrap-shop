# ROOM — каталог комнатных растений

Контрольная работа №2 по дисциплине «Фронтенд и бэкенд разработка».

**Тема:** CSS-фреймворки: разработка интерфейса на Bootstrap.

## О проекте

ROOM — учебный многостраничный каталог комнатных растений. Посетитель может искать растения по названию, фильтровать их по освещению и сложности ухода, открывать быстрый просмотр, изучать характеристики и заполнять демонстрационную заявку.

Заявка проверяется в браузере. Серверной части нет, данные никуда не отправляются и реальный заказ не создаётся.

## Страницы

| Файл | Содержание |
| --- | --- |
| `index.html` | Главная страница: шапка, hero-блок, преимущества и популярные растения |
| `catalog.html` | Девять растений, поиск, фильтры, карточки и модальное окно быстрого просмотра |
| `product.html` | Подробное описание выбранного растения, таблица характеристик и ответы на вопросы |
| `order.html` | Форма заявки с проверкой обязательных полей |

Ссылки вида `product.html?plant=monstera` открывают карточку нужного растения. При переходе к заявке выбранное растение автоматически подставляется в список.

## Технологии и подключение

- HTML5 и CSS;
- Bootstrap 5.3.8, подключённый локально из `vendor/bootstrap/`;
- JavaScript для фильтров, карточки растения и формы;
- Git и GitHub Pages.

Файл `css/custom.css` подключён после Bootstrap. Фотографии загружаются из Unsplash; если фотография недоступна, используется локальная иллюстрация `images/plant.svg`.

## Bootstrap-сетка и компоненты

Вёрстка использует `container`, `row`, `col-12`, `col-md-*`, `col-lg-*` и отступы `g-*`. На страницах применяются `navbar`, `card`, `btn`, `badge`, `alert`, `modal`, `breadcrumb`, `table`, `form-control`, `form-select`, `input-group`, `form-check` и `accordion`. Для мобильного меню, модального окна и accordion подключён `bootstrap.bundle.min.js`.

## Самостоятельные доработки

- Локальное подключение Bootstrap без CDN.
- Каталог из девяти растений с поиском и фильтрами.
- Быстрый просмотр с переходом к подробной карточке или заявке.
- Одна страница товара показывает выбранное растение через параметр адреса.
- В форме автоматически выбирается растение из каталога; сообщение честно указывает, что данные не отправлены.
- Единое оформление страниц, мобильная навигация и запасная локальная иллюстрация.

## Как проверить

1. Открыть `index.html` и перейти в каталог.
2. Поискать растение по названию, выбрать фильтры и сбросить их.
3. Открыть «Быстрый просмотр», затем подробную карточку и раскрыть вопросы.
4. Перейти к заявке: выбранное растение должно быть указано в форме.
5. Заполнить обязательные поля и проверить сообщение о демонстрационной заявке.
6. Проверить страницы на ширинах 375, 768, 1024 и 1440 px.
