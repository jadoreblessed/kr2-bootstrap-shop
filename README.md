# ROOM — каталог комнатных растений

Контрольная работа №2 по дисциплине «Фронтенд и бэкенд разработка».

**Тема:** CSS-фреймворки: разработка интерфейса на Bootstrap.

## О проекте

ROOM — учебный многостраничный каталог комнатных растений. Пользователь может найти растение через поиск и фильтры, открыть быстрый просмотр, изучить характеристики и заполнить демонстрационную форму заявки.

Форма не подключена к серверу и не отправляет персональные данные.

## Страницы

- `index.html` — главная страница, hero-блок, преимущества и популярные растения;
- `catalog.html` — каталог из 9 растений, поиск, фильтры и быстрый просмотр;
- `product.html` — подробная карточка растения, характеристики и вопросы;
- `order.html` — форма заявки с проверкой обязательных полей.

Страница `product.html` показывает нужное растение по параметру адреса `?plant=...`.

## Технологии

HTML5, CSS, Bootstrap 5.3.8, JavaScript, Git.

Bootstrap подключён **локально** из `vendor/bootstrap/`. Файл `css/custom.css` подключён после Bootstrap.

## Использованные компоненты Bootstrap

`navbar`, `card`, `btn`, `badge`, `alert`, `modal`, `breadcrumb`, `table`, `form-control`, `form-select`, `input-group`, `form-check`, `accordion`.

Вёрстка использует `container`, `row`, адаптивные `col-12`, `col-md-*`, `col-lg-*` и отступы `g-*`.

## Самостоятельные доработки

- локальное подключение Bootstrap без CDN;
- каталог из девяти растений с поиском и двумя фильтрами;
- быстрый просмотр растения в модальном окне;
- переход к подробной карточке выбранного растения;
- автоматический выбор растения в форме заявки;
- единый визуальный стиль и адаптация под мобильный экран;
- локальная запасная иллюстрация при ошибке загрузки фотографии.
