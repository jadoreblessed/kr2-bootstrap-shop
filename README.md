# ROOM — каталог комнатных растений

Учебный проект контрольной работы №2 по теме «Разработка интерфейса с использованием CSS-фреймворка Bootstrap».

## О проекте

ROOM — адаптивная главная страница каталога комнатных растений. Посетитель может посмотреть популярные растения и узнать, чем полезен каталог.

## Что реализовано

- шапка с мобильным меню;
- первый экран с описанием проекта;
- блок преимуществ;
- сетка из шести растений;
- раздел о проекте и подвал;
- адаптивная вёрстка на Bootstrap-сетке.

## Технологии

- HTML5;
- Bootstrap 5.3.3, подключённый через CDN;
- CSS;
- Git и GitHub.

## Структура проекта

```text
kr2-bootstrap-shop/
├── index.html
├── css/
│   └── custom.css
├── README.md
└── .gitignore
```

## Как открыть сайт

Откройте файл `index.html` в браузере. Для загрузки Bootstrap и изображений требуется подключение к интернету.

## Практическое занятие №9

На главной странице используются `container`, `row`, `col-12`, `col-md-*`, `col-lg-*`, а также классы отступов `g-*`. Bootstrap CSS и JS Bundle подключены через CDN, собственные стили находятся в `css/custom.css`.
